# Perfect Dark - Dab's Mod + HD Textures
### Description:
Play "Perfect Dark" PC port on Linux!
### Technical notes:
- Using Dab's Mod engine and HD Texture pack by Parabolee of Retro Foundry
- During install, you will need to provide Perfect Dark rom file in .z64 format:
md5: e03b088b6ac9e0080440efed07c1e40f
