# Project IGI - CD + IGIPatch
### Description:
Play "Project IGI - I'm Going In" CD edition on Linux!
### Technical notes:
- Game CD image will be downloaded directly from Internet Archives
- Using IGIPatch project to play this game on modern computer/OS
- This game does not support ALT-TAB. Workaround: use Gamescope
