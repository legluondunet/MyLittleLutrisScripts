# Wave Race 64 - Kawasaki Jet Ski - Recompiled
### Description:
Play "Wave Race 64: Kawasaki Jet Ski" PC port on Linux!
### Technical notes:
- Using "Wave Race 64: Recompiled" engine to play this game natively on PC
- During install you will need to provide a rom in .z64 format: 
Wave Race 64 (USA) (Rev A)
sha1 508dfc2d4caa42b6f6de5263d0aed5e44ac7966a
