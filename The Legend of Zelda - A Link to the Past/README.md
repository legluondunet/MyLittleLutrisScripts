# The Legend of Zelda - A Link to the Past - zelda3
Play "The Legend of Zelda: A Link to the Past" on Linux!
### Technical notes:
- Using "Zelda 3" open source project: play this game natively on PC with a lot of additional features
- During install, you will need to provide US SNES game rom in .sfc format
