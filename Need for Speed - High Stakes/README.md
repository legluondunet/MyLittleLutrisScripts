# Need for Speed: High Stakes - CD - Modern and Silent patches
### Description:
Play "Need for Speed - High Stakes" CD edition on Linux!
### Technical notes:
Modern and Silent patches included

Known issues:
- After "Alt-Tab", if the game screen is distorted, press "Alt+Enter" two times.
- Controllers cannot be used to navigate menus and are exclusively used in races.
- Modern Controllers are not supported and block Keyboard input. This is a limitation of the game when a Controller is detected, but it doesn't know what to do with a Modern Controller.
-- Use the Xidi addon installer for Modern Controller support or unplug it for Keyboard input.
-- On the Steam Deck you can use a Steam Controller profile that only emulates Mouse and Keyboard input but no Controller inputs.
