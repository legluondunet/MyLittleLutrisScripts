# Paper Mario - PaperBoat
### Description:
Play "Paper Mario" natively on Linux!
### Technical notes:
- Using PaperBoat engine
- During install you will need to provide "Paper Mario" USA rom file in .z64 format SHA1 Hash: 3837f44cda784b466c9a2d99df70d77c322b97a0
