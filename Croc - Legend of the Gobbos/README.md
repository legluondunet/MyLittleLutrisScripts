# Croc - Legend of the Gobbos - Definitive Edition patch 1.3
### Description:
Play "Croc: Legend of the Gobbos" Definitive Edition on Linux!
### Technical notes:
- Using Definitive Edition patch 1.3: An unofficial patch that introduces widescreen support, improved modern Windows and Linux compatibility, and the ability to choose between the soundtracks of all versions of the game (PC, PSX, and demo)

# Croc - Legend of the Gobbos - CD + Windows 95
### Description:
Play "Croc: Legend of the Gobbos" CD edition on Linux!
### Technical notes:
- Using Dosbox Pure Unleashed with a ready to use Windows 95 OSR 2.5 install
- Once Windows 95 started, go to "My Computer", CD Drive and install the game.
Then, set Windows 95 desktop resolution to 800x600, launch game. 
In game menu click on "Change drivers settings", select drivers "3DFX Voodoo compatible" and set game resolution to 800x600, Lighting quality to "Super" and Texture quality to "Filtered"
- Press "CTRL+F12" to show Dosbox Pure Unleashed menu
