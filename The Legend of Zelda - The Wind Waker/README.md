# The Legend of Zelda - The Wind Waker - Recomp
### Description:
Play "The Legend of Zelda - The Wind Waker" natively on Linux!
### Technical notes:
- Using "Wind Waker Recomp" engine
- During install you will need to provide "The Legend of Zelda - The Wind Waker" USA rom file
