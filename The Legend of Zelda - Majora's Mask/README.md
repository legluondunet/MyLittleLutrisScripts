# The Legend of Zelda - Majora's Mask - 2ship2harkinian + HD textures
### Description:
Play "The Legend of Zelda - Majora's Mask" natively on Linux!
### Technical notes:
- Using 2ship2harkinian open source engine and MM Reloaded HD textures. To enable HD textures, in 2ship2harkinian menu, "Enhancements", "Graphics", click on "Use alternate assets"
- During install, you will need to provide "The Legend of Zelda - Majora's Mask" USA rom file in .z64 format:
sha1: d6133ace5afaa0882cf214cf88daba39e266c078
sha1: 9743aa026e9269b339eb0e3044cd5830a440c1fd
### Credits:
- 2ship2harkinian: https://github.com/2ship2harkinian/2ship2harkinian
- MM Reloaded: https://evilgames.eu/texture-packs/mm-reloaded.htm
- Lutris script maintained by legluondunet: https://github.com/legluondunet/MyLittleLutrisScripts
