# Spider-Man (2002) - CD - fix-enhancers
### Description:
Play "Spider-Man (2002)" CD Edition on Linux!
### Technical notes:
- Game CD images will be downloaded directly from Internet Archives
- Graphic fixes from fix-enhancers and 1.3 official patch included
- This game has poor controller support. You will find AntiMicroX profiles here: https://github.com/legluondunet/MyLittleLutrisScripts/tree/master/Spider-Man%20(2002)/controller
